# German Credit Risk Analysis & Prediction

This repository hosts an end-to-end data analysis and machine learning classification pipeline utilizing the German Credit dataset from the UCI Machine Learning Repository.

## Key Objectives
1. Analyze the core drivers behind good vs. bad credit risk profiles.
2. Build a Machine Learning pipeline to classify applicant creditworthiness.

## Key Results
* **Model**: Random Forest Classifier
* **Overall Accuracy**: 75%
* **Top Predictors**: Credit Amount, Checking Account Status, Age, and Credit Duration.
